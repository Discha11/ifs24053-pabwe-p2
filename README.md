## Halaman

| Halaman              | File               | Teknologi                    |
| -------------------- | ------------------ | ---------------------------- |
| Landing page jasa AI | `index.html`       | HTML + CSS murni (external)  |
| Daftar blog AI       | `blog.html`        | Bootstrap 5.3 + Bootstrap Icons |
| Detail blog AI       | `blog-detail.html` | Bootstrap 5.3 + Bootstrap Icons |
| Curriculum Vitae     | `cv.html`          | Tailwind CSS 4 (Play CDN) + Tabler Icons |

## Cara menjalankan

Buka `index.html` di browser (atau pakai ekstensi Live Server di VS Code).
Perlu koneksi internet untuk memuat Google Fonts, Bootstrap, Tailwind, dan ikon dari CDN.
